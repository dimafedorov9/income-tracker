# Доходы

Журнал зарплаты и других доходов для телефона и компьютера. Интерфейс лежит на GitHub Pages, данные хранятся в вашей Google Таблице через Apps Script — так же устроен «Журнал зала».

## Что умеет

- **Сводка.** Сколько начислено за текущий месяц и сколько это от обычного: среднее за последние 3 месяца. Ниже ближайшие выплаты по каждой работе: число и сумма считаются по медиане за полгода, статус — «получено», «через 5 дней» или «задерживается». Нажатие на ожидаемую выплату открывает форму с уже заполненными полями.
- **Добавление выплаты.** Кнопка «+».
  - Сумма вводится числом или формулой, как в таблице: `23133,19+34283,21`, `20965,23+83220,21-50600`. В журнале сохраняются и итог, и формула.
  - Источник, категория, дата и заметка.
  - Месяц начисления подставляется сам по правилу источника, его можно поменять вручную.
  - Кнопка «Как в прошлый раз» подставляет прошлую сумму.
- **Источники и категории.** Три вида: основная работа, подработка, прочее. У каждого источника свои категории: у основной работы — «Зарплата», «Отпускные», «Премия», у студии, где берёте заказы, — «Создание презентаций». Новую категорию можно добавить прямо из формы. Источник можно переименовать, перекрасить или убрать в архив.
- **Выплаты.** Сгруппированы по месяцу начисления с итогами. Есть фильтр по источнику и поиск по категории, заметке и сумме. Нажатие на выплату — правка или удаление.
- **Аналитика** за 12 месяцев, по годам или за всё время:
  - итог, среднее в месяц, лучший и худший месяц;
  - столбцы по месяцам с разбивкой по источникам: нажмите на столбец, чтобы увидеть раскладку;
  - доли источников и категорий;
  - доход за скользящие 12 месяцев — тренд без скачков от премий;
  - накопительная сумма и таблица по годам с изменением к прошлому году;
  - нетипично крупные выплаты (похожие на премию или отпускные) и выводы.
- **Месяц.** Подробности, сравнение с прошлым месяцем и с тем же месяцем год назад.
- **Импорт** строк, скопированных из Excel или Google Таблиц: дата, источник, сумма, категория, заметка. Дубли распознаются, новые источники создаются сами. **Экспорт** — в CSV или в буфер для вставки в таблицу.
- **Защита на устройстве.** Код из 4 цифр при входе и после 5 минут в фоне. Кнопка с глазом скрывает все суммы.
- **Оформление** «Классика» или «Премиум» и тема: светлая, тёмная или как в системе.
- **Без сети** выплата сохраняется на телефоне и уходит в таблицу, когда сеть появится.

## Где лежат личные данные

В архиве две папки:

```
income-tracker/                   ← это загружается в GitHub (публично)
private-НЕ-ЗАГРУЖАТЬ-В-GITHUB/
  Seed.gs                         ← ваши выплаты, только для вставки в Apps Script
  build_seed.py, ПРОЧТИ.md        ← сборка Seed.gs из xlsx и итоги сверки
```

В репозитории нет ни одной вашей суммы: демо-режим работает на выдуманных данных (`demo.json`). Файл `.gitignore` не даст случайно закоммитить `Seed.gs`, `real.json` и `.xlsx`. Сервер отвечает только на запросы с токеном, токен хранится в настройках Apps Script и на ваших устройствах.

## Установка (≈15 минут, один раз)

### 1. Google Таблица и Apps Script

1. Создайте новую Google Таблицу, например «Доходы».
2. **Расширения → Apps Script.**
3. Замените содержимое `Код.gs` текстом из `income-tracker/apps-script/Code.gs`.
4. **＋ → Скрипт**, назовите `Seed`, вставьте текст из `private-НЕ-ЗАГРУЖАТЬ-В-GITHUB/Seed.gs`.
5. Сохраните. Выберите функцию **setup** → **Выполнить**, разрешите доступ: это ваш собственный скрипт.
6. В журнале выполнения появится **TOKEN**, сохраните его. Потерять не страшно: функция `showSecrets` покажет его снова.

В таблице появятся листы «Выплаты», «Источники», «Категории», «Настройки» и «По месяцам». Последний — живая сводная таблица по месяцам и источникам, её можно смотреть прямо в Google Таблицах.

После этого файл `Seed` в Apps Script можно удалить: данные уже в таблице.

### 2. Опубликовать API

**Развернуть → Новое развёртывание → Веб-приложение.** «Выполнять как: Я», «Доступ: Все». Скопируйте адрес `…/exec`.

Если позже поменяете `Code.gs`: **Развернуть → Управление развёртываниями → ✏️ → Новая версия**. Адрес не изменится.

### 3. GitHub Pages

1. Создайте репозиторий, например `income`, и загрузите в него **содержимое папки `income-tracker`**.
2. **Settings → Pages → Deploy from a branch → main / (root) → Save.**
3. Через минуту приложение будет на `https://ВАШ_ЛОГИН.github.io/income/`.

Можно держать его рядом с «Журналом зала» на том же `github.io`: настройки и кэш у приложений не пересекаются.

### 4. Телефон и компьютер

Откройте адрес, вставьте адрес веб-приложения и токен, нажмите «Подключить». На телефоне добавьте приложение на главный экран. В Настройках включите код на вход.

## Как считается

- **Месяц начисления** берётся из правила источника.
  - «Аванс и остаток»: выплаты до 15-го числа включительно — остаток за прошлый месяц, после — аванс за текущий. Число можно поменять для каждого источника.
  - «По дате выплаты»: для подработок и разовых доходов.
  - Месяц сохраняется в выплате, поэтому смена правила не переписывает историю. У отдельной выплаты месяц можно поправить вручную.
- **Среднее в месяц, лучший и худший месяц** считаются по закрытым месяцам с доходом: текущий месяц ещё не закончен и в них не входит. Поэтому среднее здесь может быть выше, чем в старой таблице: там незаконченный месяц тоже шёл в среднее.
- **Ожидаемые выплаты** строятся только для источников с правилом «аванс и остаток», у которых за полгода есть хотя бы 4 выплаты. Число и сумма — медиана.
- **Нетипично крупная выплата** — «Зарплата» больше, чем в 1,8 раза от медианы той же половины месяца у этого источника за год. Если это премия или отпускные, поменяйте категорию.

tools/make_demo.py               генератор demo.json
